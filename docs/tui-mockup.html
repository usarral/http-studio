HTTP Studio · TUI mockup

An interactive mockup: click inside and try the keys for real. It is not a screenshot — the motion engine, the modes, the search and the command line are all implemented. It is here to settle the ergonomics before writing them in ratatui.

Start with j k to move, Enter to open a request, <Space>r to run it (you will see the engine's event streaming) and :help for the rest.
